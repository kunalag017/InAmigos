# InAmigos Foundation Website

A simple static website for the InAmigos Foundation, designed to showcase the organization's mission, projects, impact, and ways to get involved.

## Project Overview

This project is built using plain HTML and CSS and includes sections for:

- Home / hero banner
- About the foundation
- Project highlights
- Impact statistics
- Gallery
- Call to action / join section
- Footer and navigation

## Files

- `index.html` — main website structure
- `style.css` — styling and layout

## How to View the Website

1. Open `index.html` in a browser, or
2. Use a local preview extension such as Live Server in VS Code.

No build step or package installation is required.

## Purpose

The site is intended to communicate the foundation's values and encourage community support, volunteering, and engagement.
